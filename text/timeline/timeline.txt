# ============================================
# 时间线文案
# 格式说明：
#   [event]       一条时间线事件开始
#   year=年份或时间段
#   title=标题
#   text=正文，支持用 \n 表示换行
#   tone=样式标记，可选：fall / illness / death / ghost
# ============================================

[event]
year=2007年
title=琼华陨落
tone=fall
text=琼华坠入东海，旧日剑光随山门一同沉没。\n慕容紫英活了下来，也从这一年起学会把许多话收进沉默里。

[event]
year=2007-2015
title=菱纱身体逐渐恶化
tone=illness
text=离开琼华之后，韩菱纱的寒疾一年重过一年。\n起初只是畏冷、易乏，后来连春日的风也会让她咳上许久。\n紫英下山买粥、抓药、学煎药，把能做的事一件一件做得笨拙又认真。

[event]
year=2015年
title=菱纱去世
tone=death
text=这一年春末，菱纱没有再等到夏天。\n紫英收起她留下的红色剑穗、旧簪和几句未说完的话。\n人间仍旧天亮，陈州的铺子照常开门，只是他再也不用买两份点心。

[event]
year=2015-2027
title=菱纱在鬼界服役
tone=ghost
text=菱纱魂归鬼界，在幽都名册上领了差役。\n十二年间，她替亡魂引路，也偶尔从很远的地方听见人间旧友的名字。\n紫英仍在世间行走，守着没有寄出的消息，等一场终会重逢的轮回。
